# Contributing to Awesome AI IDEs

Thank you for your interest in contributing to the Awesome AI IDEs list! We welcome contributions from the community to keep this list up-to-date and comprehensive.

## How to Contribute

1.  **Check the List**: Before submitting a new tool, please check the existing list to ensure it's not already included.
2.  **Fork the Repository**: Create a fork of this repository on GitHub.
3.  **Add Your Tool**: Add the tool to the appropriate category in both `README.md` and `README_CN.md`.
    *   Ensure the tool is relevant to AI-powered development.
    *   Provide a concise and accurate description.
    *   Include the official website or GitHub link.
4.  **Submit a Pull Request**: Create a pull request with a clear description of the tool you're adding and why it should be included.

## Criteria for Inclusion

*   The tool must have significant AI-powered features (e.g., code completion, refactoring, chat, agents).
*   The tool should be actively maintained or widely used.
*   Avoid adding tools that are purely experimental or have very limited functionality unless they offer a unique perspective.

## Translation

If you're contributing a new tool, please try to provide descriptions in both English and Chinese. If you're only comfortable with one language, others in the community can help with the translation.

# 贡献指南

感谢您有兴趣为 Awesome AI IDEs 列表做出贡献！我们欢迎社区的贡献，以保持此列表的最新和全面。

## 如何贡献

1.  **检查列表**：在提交新工具之前，请检查现有列表以确保它尚未包含在内。
2.  **Fork 仓库**：在 GitHub 上创建此仓库的 fork。
3.  **添加工具**：将工具添加到 `README.md` 和 `README_CN.md` 中的适当类别。
    *   确保该工具与 AI 驱动的开发相关。
    *   提供简洁准确的描述。
    *   包含官方网站或 GitHub 链接。
4.  **提交 Pull Request**：创建一个 pull request，并清楚地描述您要添加的工具以及为什么要包含它。

## 收录标准

*   该工具必须具有显著的 AI 驱动功能（例如：代码补全、重构、聊天、智能体）。
*   该工具应处于积极维护状态或被广泛使用。
*   避免添加纯实验性或功能非常有限的工具，除非它们提供了独特的视角。

## 翻译

如果您贡献了一个新工具，请尝试同时提供英文和中文描述。如果您只熟悉一种语言，社区中的其他人可以帮助进行翻译。
